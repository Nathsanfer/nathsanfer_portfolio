# Portfolio

Portfolio pessoal desenvolvido com Vue 3 e Vite.

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Deploy na Vercel

O projeto usa `npm run build` e publica a pasta `dist`. A configuração em
`vercel.json` também encaminha as rotas do Vue Router para `index.html`, permitindo
recarregar páginas internas diretamente.
